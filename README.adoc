= ConfigUI binders
:description: Toolkit-specific renderers for UniConfig form rows.

Binders consume `flattenFormRows` from link:https://github.com/dev-centr/uniconfig-core[uniconfig-core] (`import uniconfig.core.form_model`).

== Packages

[cols="1,2"]
|===
| `configui-dlangui` | Legacy dlangui binder (`dub build -c dlangui-legacy` on the app).
| `configui-dui` | **Primary** D desktop binder — dui/dew form + banner widgets.
| `configui-qt` | Qt 6 widget binder (stub).
| `configui-gtk` | GTK 4 binder (stub).
| `configui-avalonia` | Avalonia (.NET) binder (stub).
| `@dev-centr/configui-web` | TypeScript + Solid components; embed in Vite/Next apps.
|===

== Engine (not here)

* Syntax codecs, schema merge, catalog index — `uniconfig-core`
* Form row model (`FormRow`, `flattenFormRows`) — `uniconfig.core.form_model` in the engine
* Fallback vocabulary for Git/Terraform/DUB — `fallback-catalog/` in the ConfigUI app repo (not a separate package)

== Vocabulary resolution

Sidecar `*.schema.json`, `$schema`, registered app catalogs, bundled fallback — **no intra-file forks** in UniConfig until connectome-fs ships fork I/O.
